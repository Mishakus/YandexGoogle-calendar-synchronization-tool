# YandexGoogle Calendar Synchronization Tool

Этот проект создан для решения известной проблемы совместимости между экспортом календаря Яндекса и импортом в Google Calendar.

## Проблема

Когда вы пытаетесь добавить приватную ссылку из Яндекс.Календаря (`https://calendar.yandex.ru/export/...`) в Google Calendar, Google успешно подтягивает события, но скрывает их названия и описания, заменяя их словом **«Занят»** (Busy).

Это происходит из-за того, что Яндекс экспортирует большинство ваших событий с полем `CLASS:PRIVATE`. По стандартам Google Calendar (и iCal), приватные события из внешних подписок скрываются в целях безопасности, чтобы никто не мог случайно прочитать ваши секретные дела.

## Решение

Данный инструмент поднимает локальный прокси-сервер через Docker. 

Когда Google Calendar запрашивает ваш календарь по нашей новой ссылке:
1. Прокси-сервер скачивает оригинальный `.ics` файл из Яндекса.
2. Он «на лету» изменяет параметр `CLASS:PRIVATE` на `CLASS:PUBLIC` для всех событий.
3. Он прописывает красивое имя для вашего календаря через параметр `X-WR-CALNAME`.
4. Отдает готовый файл в Google Calendar.

В результате Google видит события как публичные и корректно отображает их названия и описания!

## Установка и запуск (Linux / Ubuntu)

### Системные требования
- **ОС:** Linux (Ubuntu/Debian)
- **Установленные пакеты:** `git`, `docker`, `docker-compose` (или плагин `docker compose`)

Если Docker и Docker Compose у вас не установлены, выполните следующие команды:
```bash
# Установка Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# Установка Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/download/v2.24.5/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
```

### Запуск проекта

1. Клонируйте репозиторий на ваш сервер:
   ```bash
   git clone https://github.com/Mishakus/YandexGoogle-calendar-synchronization-tool.git
   ```

2. Перейдите в папку с проектом:
   ```bash
   cd YandexGoogle-calendar-synchronization-tool
   ```

3. Запустите скрипт установки (может потребоваться ввод пароля sudo):
   ```bash
   bash ya-gcal-sync
   ```
   Скрипт скопирует себя в системный каталог `/usr/local/bin` и запустит Docker-контейнер в фоне на порту `8085`.

## Использование

После установки вы можете управлять календарями из любого места на сервере, просто набрав в консоли:

```bash
ya-gcal-sync
```

Откроется удобное меню:
1. **Добавить календарь**: Скрипт попросит вставить секретную ссылку из Яндекса и желаемое имя календаря. Он автоматически определит внешний IP вашего сервера (или вы можете указать свой домен) и выдаст вам готовую безопасную ссылку вида `http://IP:8085/cal/УНИКАЛЬНЫЙ_ID.ics`. **Эту ссылку нужно вставить в Google Calendar!**
2. **Список**: Показывает все добавленные календари по названиям.
3. **Удалить**: Удаление привязанного календаря по номеру из списка.
4. **Перезапуск сервера**: Мягкая перезагрузка прокси-сервера.

## Безопасность

- Оригинальные ссылки Яндекса и токены безопасно хранятся внутри файла `config.json` в директории проекта и не светятся наружу.
- Уникальный 32-значный ID генерируется случайно, чтобы никто не мог подобрать вашу ссылку. 
- Ссылка выводится на экран ровно один раз при создании, поэтому её невозможно подсмотреть, если кто-то заглянет вам в терминал позже.
